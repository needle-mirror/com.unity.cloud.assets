# UNITY CLOUD ASSETS

This package is experimental and provides client support for Assets service features.

## Before you start

The following are the prerequisites for installing the package:

* A Unity version of 2021.3 or later

## Package contents

* Asset Discovery API to provide published assets through searches.
* Asset Management API to manage assets in a project.

## Install

The package can be found in the [internal artifactory](https://artifactory.prd.cds.internal.unity3d.com/ui/packages?name=com.unity.cloud&type=packages).

## Build, test, and run

1. In the Package Manager, find the Unity Cloud Assets package
2. Import the package samples into your project
3. Open the sample scenes and run them
