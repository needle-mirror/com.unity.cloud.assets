Before you start, set up a Unity scene with an organization and project browser. For more information, see [Get started with Asset Discovery](get-started-discovery.md) and [Get started with Asset Management](get-started-management.md).

You also need to have some assets in the cloud. You can add assets in one of the following ways:

* Create assets with the [Unity Cloud Assets package](get-started-management.md)
* Upload assets from existing Unity assets, as shown in the [Asset Uploader sample](./asset-database-uploader-sample.md)
* Create assets from the [Unity Cloud dashboard](https://docs.unity3d.com/docs-asset-manager/manual/add-asset.html)
